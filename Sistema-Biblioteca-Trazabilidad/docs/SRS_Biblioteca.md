# Especificación de Requisitos de Software (SRS) - v1.0

* **REQ-BIB-001:** El sistema debe registrar el préstamo de un libro físico a un estudiante activo.

* **REQ-BIB-002:** El sistema debe registrar la devolución de un libro y actualizar su disponibilidad.
* **REQ-BIB-003:**El sistema debe permitir renovar un préstamo activo por 7 días adicionales (máximo 1 renovación).
